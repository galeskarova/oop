# Проект "Интернет-магазин" (задание 14.1)

## Реализованный функционал

- Класс `Product` с атрибутами: `name`, `description`, `price`, `quantity`.
- Класс `Category` с атрибутами: `name`, `description`, `products` (список объектов `Product`).
- Автоматически обновляемые атрибуты класса `Category`:  
  - `category_count` — общее количество категорий,  
  - `product_count` — общее количество товаров (увеличиваются при создании каждого экземпляра).
- Модульные тесты с использованием `pytest` проверяют корректность инициализации объектов и работу счётчиков.
- Отчёт о покрытии кода тестами — **100%** (команда `pytest --cov=src --cov-report=term-missing`).
