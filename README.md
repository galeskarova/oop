# Проект "Интернет-магазин" (задание 15.1)

## Описание

Проект представляет собой модель интернет-магазина, реализованную на Python с использованием объектно-ориентированного подхода.  
Основные сущности:

- Product – товар с названием, описанием, ценой и количеством на складе.
- Category – категория товаров, содержащая список продуктов.

## Реализованный функционал

- Класс `Product`:
- Конструктор – принимает `name`, `description`, `price`, `quantity`.
- Приватный атрибут `__price` с геттером и сеттером (сеттер проверяет положительность цены и при понижении запрашивает подтверждение).
- Класс-метод `new_product` – создаёт продукт из словаря; при совпадении имени объединяет количества и выбирает максимальную цену.
- Магический метод `__str__` – возвращает строку вида:  
  `Название, X руб. Остаток: X шт.`
- Магический метод `__add__` – складывает два продукта, возвращая сумму произведений цены на количество каждого (`price1 * quantity1 + price2 * quantity2`).  
  При попытке сложить с объектом другого типа выбрасывает `TypeError`.

- Класс `Category`:
- Конструктор – принимает `name`, `description`, список продуктов `products`.
- Приватный атрибут `__products` – хранит товары категории.
- Геттер `products` – возвращает строковое представление всех продуктов, каждый на новой строке (использует `__str__` продукта).
- Метод `add_product` – добавляет товар в категорию и обновляет общий счётчик.
- Автоматически обновляемые счётчики – общее количество категорий и общее количество товаров (классовые атрибуты).
- Магический метод `__str__` – возвращает строку вида:  
  `Название категории, количество продуктов: X шт.`, где X – суммарное количество всех товаров в категории.
- Магический метод `__iter__` – возвращает итератор для перебора товаров категории (дополнительное задание).

- Класс `CategoryIterator` 
- Вспомогательный итератор, реализующий `__iter__` и `__next__`.
- Позволяет использовать категорию в цикле `for` и других итерационных контекстах.

## Тестирование

- Используется фреймворк **pytest**.
- Написаны тесты для всех новых методов:
  - `__str__` у `Product` и `Category`,
  - `__add__` (включая проверку ошибки типа),
  - геттер `products` (для пустой и непустой категории),
  - итератор (перебор товаров в цикле, поведение на пустой категории).
- Покрытие функционального кода тестами превышает **90 %** (отчёт генерируется через `pytest-cov`).

### Запуск тестов

# установка зависимостей
pip install pytest pytest-cov

# запуск всех тестов с отчётом о покрытии
pytest tests/test_models.py -v --cov=models --cov-report=term
