# Проект "Интернет-магазин" (задание 14.2)

## Реализованный функционал

- Класс `Product`:
  - Приватный атрибут цены с геттером и сеттером (проверка на положительность, подтверждение понижения).
  - Класс-метод `new_product()` для создания продукта из словаря, с автоматическим объединением дубликатов по имени (увеличивает количество, выбирает максимальную цену).
- Класс `Category`:
  - Приватный список товаров.
  - Метод `add_product()` для добавления товара с автоматическим увеличением общего счётчика.
  - Геттер `products`, возвращающий строковое представление всех товаров в формате: «Название продукта, X руб. Остаток: X шт.».
- Автоматически обновляемые счётчики категорий и товаров.
- Модульные тесты (pytest) проверяют новую функциональность, покрытие кода > 90%.

## Зависимости

- Python 3.8+
- pytest
- pytest-cov
- flake8

Установка: `poetry install`
